## � 关于本项目

作为一名 **终端工具爱好者** 和 **Neovim 用户**，我深知优秀的终端工具能够极大地提升开发效率和使用体验。这个仓库收录了我在日常工作中发现的各类令人惊艳的终端工具。

### 🎯 项目目标

```
📦 收录优秀工具    →  整理和分享各类优质终端工具
📚 提供使用参考    →  为终端爱好者提供工具选择指南
🤝 促进交流分享    →  建立终端工具爱好者的交流平台
💡 持续更新维护    →  随着新工具的出现不断完善列表
```

## 🤝 如何贡献

我们非常欢迎各位终端工具爱好者一起来完善这个列表！

### 🔄 贡献流程

```bash
# 1. Fork 本仓库

# 2. 克隆到本地
git clone https://github.com/YOUR_USERNAME/terminal-tools.git

# 3. 创建特性分支
git checkout -b feature/add-awesome-tool

# 4. 在 terminal_tools.md 中添加你的工具

# 5. 提交更改
git commit -m 'feat: 添加 xxx 工具'

# 6. 推送到你的仓库
git push origin feature/add-awesome-tool

# 7. 创建 Pull Request
```

### ✅ 贡献规范

添加新工具时，请确保包含：

- ✨ **工具名称**：清晰准确的名称
- 📝 **功能描述**：一句话说明主要功能
- 🔗 **GitHub 链接**：官方仓库地址（如有）
- 📦 **安装方式**：简要的安装命令
- 🏷️ **正确分类**：归类到合适的类别

**示例格式：**

```markdown
### [工具名称](GitHub链接)

简短的功能描述。

**安装方式**：`brew install tool-name`
```

## 🔄 自动更新统计

添加新工具后，可以使用 Python 脚本自动统计工具数量并更新 README：

```bash
# 运行统计脚本
python3 scripts/update_stats.py
```

脚本会自动：
- 📊 统计 `terminal_tools.md` 中各分类的工具数量
- ✏️ 更新 `README.md` 中的工具数量表格
- 📝 输出统计结果
